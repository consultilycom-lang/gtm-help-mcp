# gtm.help in Lovable

Official docs: [Connect a custom MCP server as a chat connector](https://docs.lovable.dev/integrations/custom-mcp)

Custom MCP servers work on all Lovable plans as **chat connectors**. They're personal to you, available in the project chat and in Chats, and never become part of your published app. It's handy for asking Lovable to build landing pages or fixes that follow your gtm.help plays.

## Steps
1. Open **Connectors**, click **+** (top right) and choose **MCP server**.
2. Server name: `gtm.help`.
3. Connection: **Direct connection**.
4. Server URL: `https://gtm.help/mcp`.
5. Authentication: **OAuth** (default). Click **Add & authorize** and sign in to gtm.help.

If **MCP server** is greyed out, a workspace admin has turned off custom MCP servers.

## Try it
"Using the gtm.help connector, get my top play and build the landing page it recommends."

## Notes
Read-only gtm.help tools run without asking. Write tools show an approval card first.
